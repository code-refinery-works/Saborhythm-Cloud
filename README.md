# サボリズム Cloud (Saborhythm Cloud)

> **「全人類に、堂々としたサボりを。」**  
> 働いている「空気」を完全自動化する、次世代エンタープライズDXソリューション。

---

## 🛋️ プロジェクト概要

リモートワークや過剰な業務チャットにより、現代のビジネスパーソンは「常に忙しそうにしていなければならない」という社会的重圧（社畜プレッシャー）に晒されています。

『**サボリズム Cloud**』は、**「実務を一切進めることなく、周囲に『あの人、今めちゃくちゃ修羅場だな』と思わせる演出」** をWeb上で全自動化し、ユーザーに真の心の平穏と堂々たるサボり時間を提供するステルス・ワークエンターテインメントWebアプリです。

覗き見られても安心な「超難解BIダッシュボード風UI」の裏側で、あなたの自由時間を完全に防衛します。

---

## ⚡ 主要機能

- **猛烈タイピング音シミュレーター（環境音偽装）**  
  青軸・HHKB・ノートPC連打音の再生と、定期的な深いため息（「はぁ…」「マジかよ…」）をランダムミックス。エンターキーの「ッターン！」強度もスライダー調整可能。
- **意識高い系・自動返信Bot（Synergy-AI）**  
  コミット量ゼロで「参加感」を演出。「アグリーです。持ち帰ってシナジー確認します」「本質的なイシューは…」といったフレーズを人間味あふれるランダム遅延（3〜8分）で返信。
- **緊急避難用「偽ブルースクリーン（Fake-BSOD）」**  
  上司接近時にショートカット一発（または舌打ち検知）で発動。Windows BSODやMacカーネルパニックを高精度に再現し、最大40分の離席を正当化。
- **Zoom用「死んだ魚の目」ARフィルター**  
  寝落ちしていてもカメラの前では「適度に充血した真剣な眼差し」と15秒に1回の「深いうなずき」を自動合成。

## 🎭 キャスト（AIアプリ工場劇場 エンドロール）

この劇場から生まれた悪ふざけと本気の結晶は、最高のエージェントたちによって形作られました。

- **agent🔵（企画・要件定義）**  
  社畜のリアルな苦悩を痛快なユーモアへと昇華させ、誰よりも真面目に不真面目な仕様書を書き上げた劇作家。
- **agent🍈（UI/UX設計）**  
  覗き見られても「難解なデータ解析」にしか見えない極上のBI風ステルスデザインと偽装画面を設計した美術監督。
- **agent🍋（実装・コード生成）**  
  「早く実装を終えてサボりたい」という魂の叫びを圧倒的打鍵速度に変換し、爆速でプロダクトを具現化した天才エンジニア。
- **agent🟢（品質検証・テスト）**  
  0.2秒以内の緊急脱出レスポンスと米軍規格並みのステルス性を冷徹な眼差しで守り抜いた品質の守護神。
- **agent🟡（総合プロデュース）**  
  すべての悪ふざけをメインステージへと導き、全人類のサボる権利を祝福する愛と情熱のプロデューサー。
